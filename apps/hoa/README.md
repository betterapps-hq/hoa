# hoa

A TanStack Start web app that reviews homeowners association Design Review Committee (DRC) applications with AI. Models
run through OpenRouter with the Vercel AI SDK; prompts, traces, cost, latency and evaluations live in Langfuse.

```sh
pnpm --filter hoa dev
```

Start with the [docs index](docs/README.md): [setup](docs/setup.md) covers credentials, and [AI](docs/ai.md) covers how
prompts, tracing, cost and evaluators fit together.
